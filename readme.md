# YOLOv12 Gesture Recognition System

## Body

YOLOv12 Gesture Recognition System Based on Deep Learning YOLOv12: A Gesture Recognition Detection System (YOLOv12+YOLO dataset + UI interface + login and registration interface + Python project source code + model)

This paper designs and implements an efficient gesture recognition detection system based on the YOLOv12 deep learning framework. It supports real-time detection of 10 types of gestures, including letters (A, D, I, L, V, W, Y), numbers (number 5, number 7), and special meaning gestures (I love you). The system uses a self-built YOLO format dataset containing 1,200 training images and 200 validation images for model training, combined with the PyTorch framework to optimize detection accuracy and speed. Additionally, the system provides a user-friendly UI interface that integrates login and registration functions. Experiments show that this system has high recognition accuracy and robustness in complex scenarios, and can be widely applied in human-computer interaction, intelligent control, and other fields.

✅ User Login and Registration: Supports password detection and security verification.
✅ Three detection modes: Based on the YOLOv12 model, supporting image, video, and real-time camera detection, accurately recognize targets.
✅ Dual-screen comparison: Display the original scene and detection results on the same screen.
✅ Data visualization: Real-time table displaying the category, confidence, and coordinates of detected targets.
✅ Intelligent parameter adjustment: Offers a confidence slide bar to dynamically optimize detection accuracy, adapting to different scene needs.
✅ Sci-fi style interactive interface: Dark theme paired with dynamic light effects, reducing visual fatigue and improving operational experience.
